# Dr. Hari Narayan Deuri Eye Specialist Clinic - Website

This is a complete, production-ready React (Create React App) single-page medical clinic website for **Dr. Hari Narayan Deuri**, Eye Specialist in Assam.

## Quick Start & Installation

1. Open your terminal inside this folder:
   ```bash
   cd C:\Users\rajes\Desktop\dr-deuri-eye-clinic
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local development server:
   ```bash
   npm start
   ```

## Deploying to GitHub Pages

1. Update the `"homepage"` URL inside `package.json` with your GitHub username.
2. Initialize and push to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - clinic website"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/dr-deuri-eye-clinic.git
   git push -u origin main
   ```
3. Deploy to GitHub Pages:
   ```bash
   npm run deploy
   ```
